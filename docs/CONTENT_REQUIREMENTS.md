# Content Requirements and Checklist

Status: Planning only. Drafts and publication are intentionally not started.

Source: attached **Hindsight Hackathon Content Submission Guide**. Every team member completes their own article and social post; the team creates one video. Content is in English. Team-member names below are placeholders for a six-person team.

## Guide Conflicts to Resolve

- Article length: the contest table requires 800–1,500 words, while Prompt 2 targets 1,200–2,000. The compliant overlap is 1,200–1,500 words; use this unless organizers clarify otherwise.
- Article titles: Prompt 1 says titles must mention Hindsight, while the general title advice says focus on the idea/result and never mention the hackathon. Reconcile by naming Hindsight without putting “hackathon” in the title.
- Title count: Prompt 1 requests exactly 20 options; the Quick Reference table says Prompt 1 generates 5. Generate 20 per the detailed prompt, then select one; do not treat the quick-reference count as overriding the detailed instruction.
- Prompt 1 formatting: return exactly 20 candidates, one per line, no numbering or commentary. Each is at most 10 words, mentions Hindsight positively, and is specific, concrete, varied, and aimed at experienced engineers; avoid hackathon references, hype, clickbait, and generic/buzzword titles.
- Prompt numbering: the body labels the video-script prompt as Prompt 5 and thumbnail as Prompt 6, while Quick Reference labels video script Prompt 4 and thumbnail Prompt 5. This is numbering only; video script and thumbnail are optional workflow aids, while the actual video is required.
- LinkedIn links: Prompt 3 says no links in the first two lines; later instructions require the project GitHub link in the main post and the article URL as the first comment. Put required link(s) after the opening lines; add the article URL in the first comment and Hindsight GitHub in a comment as instructed.
- The guide describes a Reddit submission step both as article sharing and as a separate link post. Plan one link post to an allowed subreddit per published article; follow any platform/community rules at posting time.
